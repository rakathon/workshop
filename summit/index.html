2
Open setup.dmg
Mount the disk image from your Downloads

Open your Downloads folder and double-click setup.dmg to mount it.

3
Run setup.command
Double-click it in the disk image window

Double-click setup.command in the disk image window. Terminal opens and the installer begins — it will install Git, Node.js, VS Code, and Claude Code automatically.

4
Sign in with Rakuten OKTA
Log in and complete MFA in the browser

After tools install, Safari opens automatically. Enter username@rakuten.com and complete MFA to connect Claude Code to the Rakuten AI gateway.

5
Let the script finish
Installing plugins and writing your config

After sign-in the script installs the forge, forge-skill-creator, and forge-product-management plugins, then writes your ~/.claude/settings.json.

Wait until you see Setup complete before closing Terminal.

6
Verify Claude Code works
One quick check to confirm it's connected

Open a new Terminal window, run claude, and send this prompt:

Verification prompt
What model are you, and what is today's date?

Correct response names a Claude model and today's date.
