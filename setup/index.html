Workshop Setup

Rakuten Claude Code Setup

Automatically installs and configures VS Code, Claude Code, and Claude Desktop — all connected to Rakuten AI.
Just download, run, and you're ready to code.

1

Download the Setup File

Click the button below to download setup.dmg to your Mac.

This will install Claude Code and Claude Desktop on your Mac using your organization's inference endpoint.

⇓  Download for Mac
2

Open setup.dmg from your Downloads

Find the downloaded file in your Downloads folder and open it.

Open your Downloads folder — you'll see setup.dmg there. Double-click it to mount the disk image.

3

Double-click setup.command

Run the setup script from the mounted disk image window.

A window will open showing setup.command. Double-click it to launch the setup script.

macOS will show a security warning — this is expected. Click Open to proceed.

4

Let the Script Run & Enter Your Password

A Terminal window will open and install everything automatically.

A Terminal window will open and the script will begin installing Claude Code, Claude Desktop, and all required plugins. This may take a minute or two.

Partway through, a dialog will ask for your username and password so the script can apply the configuration profile. Enter your Mac credentials and click OK.

Safari will then open automatically and prompt you to sign in with your Rakuten OKTA account. Enter your INTRA username (username@rakuten.com) and click Next to authenticate.

5

Open Device Management via Spotlight

Use Spotlight Search to open Device Management in System Settings.

Press ⌘ Command + Space to open Spotlight Search, then follow the path for your macOS version:

macOS Ventura or later

Type "device management" and select Device Management from the results — it opens directly in System Settings.

or
macOS Monterey or earlier

Type "profiles" and select Profiles from the results.

6

Find the Downloaded Profile

Locate Claude Desktop Third-Party Inference in the Downloaded section.

In the Device Management pane, scroll to the Downloaded section. You should see Claude Desktop Third-Party Inference listed with a yellow warning badge indicating the profile is not yet installed.

7

Install the Profile

Double-click the profile and click Install… to apply it.

Double-click the profile entry to open the installation dialog. Review the profile details, then click Install… in the bottom-left corner to apply it. You may be prompted for your Mac password.

🔒 This profile is Not Signed. That is expected — it is distributed internally by your organization and does not require an Apple developer signature.

A confirmation dialog will appear warning that the profile author is unknown. This is expected for internally distributed profiles — click Install to continue.

8

Sign in with Bedrock

Choose Continue with Bedrock on the login screen.

Open Claude Desktop from your Applications folder. On the login screen, select Continue with Bedrock — this connects Claude to your organization's inference endpoint instead of Anthropic's default servers.

9

You're all set!

Claude Desktop is ready to use with your organization's endpoint.

Setup is complete. Claude Desktop is now configured to use your organization's inference endpoint. Start a conversation and enjoy!

All done! Restart Claude Desktop for the new inference settings to take effect.

Complete all steps above to finish setup.

1

Download the Setup Script

Click the button below to download setup.ps1 to your PC.

This will install Claude Code and Claude on your PC using your organization's inference endpoint.

⇓  Download for Windows
2

Open setup from your Downloads

Find the downloaded file in your Downloads folder.

Open your Downloads folder — you'll see setup listed as a Windows PowerShell script.

3

Right-click & Select "Run with PowerShell"

Right-click the file to open the context menu and run the script.

Right-click the setup file and select Run with PowerShell from the context menu.

⚠️ If PowerShell blocks the script, run this first in an elevated PowerShell window:
Set-ExecutionPolicy Bypass -Scope Process -Force
4

Let the Script Run & Sign in with Rakuten OKTA

A PowerShell window will open and install everything automatically.

A PowerShell window will open and begin installing Claude Code, Claude, and all required plugins. This may take a minute or two.

Your browser will open automatically and prompt you to sign in with your Rakuten OKTA account. Enter your INTRA username (username@rakuten.com) and click Next to authenticate.

5

Open Claude from the Start Menu

Search for Claude in the Windows search bar and launch it.

Once the script finishes, click the Start / Search button at the bottom of your screen, type Claude, and click Open.

6

Sign in with Bedrock

Choose Continue with Bedrock on the login screen.

On the login screen, select Continue with Bedrock — this connects Claude to your organization's inference endpoint instead of Anthropic's default servers.

7

You're all set!

Claude is ready to use with your organization's endpoint.

Setup is complete. Claude is now configured to use your organization's inference endpoint. Start a conversation and enjoy!

All done! Claude is connected to your organization's inference endpoint.
